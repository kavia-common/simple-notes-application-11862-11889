# Notes Frontend - Features

- Create new notes (+ New in the sidebar)
- Edit existing notes (title and content)
- Delete notes (Delete button in editor)
- View notes list (left sidebar with search)
- View note details (main editor area)
- Minimalistic light theme using:
  - Primary: #1976d2
  - Secondary: #424242
  - Accent: #ffc107

Storage: Client-only localStorage. No backend configuration required.
